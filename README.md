# SafeDrive ROS
A real-time autonomous vehicle safety monitoring system built using ROS 2, C++, and Python.

## Project Overview

SafeDrive ROS is a personal software engineering project focused on improving the reliability of autonomous vehicle navigation through collision-risk monitoring and emergency braking.

The project will use LiDAR sensor data to detect nearby obstacles, evaluate potential collision risks, and determine when a vehicle should slow down or stop.

## Project Goals

- Develop a modular collision-risk detection algorithm.
- Integrate the safety monitor with a ROS 2 autonomous driving simulator.
- Implement emergency braking based on sensor measurements.
- Build automated tests to evaluate reliability and performance.
- Explore software engineering principles used in robotics and autonomous vehicles.

## Technologies

- **Languages:** Python, C++
- **Framework:** ROS 2
- **Tools:** Docker, Git, GitHub, CMake
- **Simulation:** F1TENTH
